# Mini-Banking-System
A Java-based console application simulating core banking operations using Object-Oriented Programming (OOP) principles.
## 🚀 Features
- **Account Management:** Create new accounts with unique identifiers.
- **Secure Transactions:** Deposit and withdraw funds with real-time balance updates.
- **Validation:** Built-in logic to handle insufficient funds and invalid inputs.
- **OOP Architecture:** Utilizes Encapsulation, Abstraction, and Inheritance for clean, maintainable code.
